TokenArk · 开发者文档 OpenAPI 描述（可导入 Postman） 控制台

两种接入，一套凭据体系

推理接口走 sk- 开头的 API Key（OpenAI 兼容）；实例管理走登录会话 Token。两套都支持 REST 直连，也可以直接用官方 Python SDK。

快速开始 鉴权 推理接口 实例接口 Python SDK 工具接入 错误码

快速开始（3 步）

  1. 控制台 → 大模型 API → 创建 API Key（形如 sk-xxxx）
  2. 把 Base URL 换成本平台：https://你的域名/v1
  3. 用任意 OpenAI SDK 调 /chat/completions，模型名从 /v1/models 取
curl https://your-platform.example.com/v1/chat/completions \
  -H "Authorization: Bearer sk-xxxx" \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"你好"}]}'
模型被运营下架后，/v1/models 不再返回，直接调用会得到 403 model_offline。

鉴权

用途凭据获取方式请求头
推理 /v1/**API Key（sk-开头）控制台 → 大模型 API → 创建Authorization: Bearer sk-...
平台 /api/**会话 TokenPOST /api/auth/loginAuthorization: Bearer <token>
 
curl -X POST https://your-platform.example.com/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"tenant_a","password":"******"}'
# → {"token":"...","user":{...}}

推理接口

方法路径说明
GET/v1/models可用模型 + 每百万 token 单价 + 分组
POST/v1/chat/completionsOpenAI 兼容补全，按 token 计费

计费顺序

先扣 Token 套餐额度，扣完再扣账户余额；两者都不足返回 402，本次调用不计费。

请求示例

{
  "model": "deepseek-chat",
  "messages": [
    {"role": "system", "content": "你是运维助手"},
    {"role": "user", "content": "解释一下什么是 Pod 的 Pending 状态"}
  ],
  "max_tokens": 512
}

实例接口

方法路径说明
GET/api/skus可售规格与实时库存
POST/api/orders下单（幂等键 orderNo），成功后真实建 Pod
GET/api/instances实例列表与状态
POST/api/instances/{id}/release释放并按秒结算，多退少补
GET/api/instances/{id}/access接入信息
 
curl -X POST https://your-platform.example.com/api/orders \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"sku":"1","hours":1,"dataDiskGb":50,"orderNo":"demo-001"}'

Python SDK

随平台交付，零第三方依赖（只用标准库），文件位置：deploy/sdk/tokenark_sdk.py。

from tokenark_sdk import TokenArk

# 推理
tk = TokenArk(base_url="https://your-platform.example.com", api_key="sk-xxxx")
print(tk.chat("deepseek-chat", "写一个快速排序"))

# 实例生命周期
s = TokenArk(base_url="https://your-platform.example.com",
             username="tenant_a", password="******")
inst = s.create_instance(sku="1", hours=1, data_disk_gb=50)
print(inst["instanceId"], inst["prepaid"])
s.release(inst["instanceId"])

主流工具接入

OpenAI 官方 SDK（Python）

from openai import OpenAI
client = OpenAI(base_url="https://your-platform.example.com/v1", api_key="sk-xxxx")
print(client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "你好"}]).choices[0].message.content)

Node.js

import OpenAI from "openai";
const client = new OpenAI({ baseURL: "https://your-platform.example.com/v1", apiKey: "sk-xxxx" });
const r = await client.chat.completions.create({
  model: "deepseek-chat",
  messages: [{ role: "user", content: "你好" }]
});
console.log(r.choices[0].message.content);

任意 HTTP 工具 / Postman

错误码

HTTPtype含义与处理
401invalid_request_errorAPI Key 无效或已吊销 → 重新创建
402insufficient_quota余额与套餐都不足 → 充值或购买套餐
403model_offline模型已下架 → 查 /v1/models 换模型
404invalid_request_error模型/实例不存在
400invalid_request_error参数不合法（messages 为空、max_tokens 越界等）
