# 演示说明（给老板）

## 一句话

这是给海兰云做的 GPU 算力租赁平台演示环境，包含**管理端、用户端、监控大屏**三套界面，功能真实可操作。

---

## 怎么启动：双击一个文件

**第一步**：确认电脑装了 Docker Desktop

桌面右下角托盘有个小鲸鱼图标，就说明装了。
没装的话：https://www.docker.com/products/docker-desktop/ （免费，装完重启电脑）

**第二步**：双击 `START.bat`

等 3-5 分钟（首次要下载镜像），窗口里出现下面这段就好了：

```
============================================
    启动完成
============================================

地址：https://localhost
账号：admin
密码：Hly@2026
```

**第三步**：浏览器会自动打开

如果提示"您的连接不是私密连接"，点 **高级** → **继续前往 localhost**。
这是自签证书，内网演示的正常现象，不是故障。

**要停止**：双击 `STOP.bat`。数据不会丢。

---

## 看什么：四个页面

启动后浏览器打开的是登录页，用 `admin / Hly@2026` 登录，进入管理端。

### 1. 集群总览（登录后默认页）

一屏看清：16 张 GPU 卡、9 个控制面组件是否健康、24 小时利用率趋势、租户用量排行。
右边的五层架构图，是从接入层到 K8s 底座的完整链路。

**重点讲**：客户最关心"我的卡有没有问题"，这里 3 秒能看出来。

### 2. 节点管理 → 点任意节点

节点详情里有每张卡的温度、功耗、显存、绑定的实例。
还有一个卡池热力图，哪张卡快满了、哪张卡空闲，颜色区分。

**重点讲**：卡级可视化，这是普通 K8s 面板没有的。

### 3. 租户管理 → 开通租户

现场演示给一个客户开通：填名字、选配额、选计费方式，点"开通并下发"。

系统会自动做三件事：建租户记录、在集群里建命名空间和配额、生成管理员账号。

**重点讲**：开通一个客户 2 秒钟，不用人工登服务器。

### 4. 用户端（换账号登录）

退出后重新登录，用 `tenant_a / Hly@2026`。

这是客户看到的界面：算力市场下单、我的实例、我的账单。

下单后按秒计费，释放时自动退款。

**重点讲**：客户自助下单，不需要工单和人工。

### 5. 监控大屏（管理端侧栏最后一个）

深色科技风，专门给值班室投屏用。实时刷新，可以挂在电视上。

### 6. 大模型 API（用户端侧栏）

用 `tenant_a` 登录用户端，进「大模型 API」：

现场创建一个 API 密钥，用 curl 调一次 `/v1/chat/completions`（OpenAI 协议），
调用记录里立刻多一条 Token 明细，余额按 Token 精确扣费。模型目录、限免模型、
密钥停用立即生效都可以现场演示。

**重点讲**：GPU 只是算力的一部分，模型调用也能在这个平台上一站式计费。

### 7. 实例运营深度（用户端「我的实例」）

对任意一台运行中的实例：**升降配**换新实例、**定时关机**（到点平台自动关，不依赖浏览器）、
**克隆**复制镜像与挂载、**重启/开机/关机**、**存镜像**（可分享到社区广场、可安全扫描）。
下单时还能看到**闲时 5 折、无卡调试 ¥0.10/时、学生 9 折**等运营玩法。

**重点讲**：不止"租卡"，配套的运营工具链是全的。

### 8. 经营报表（管理端「经营报表」）

30 天收入曲线、优惠券发放与核销、租户余额排行，数字实时从账单与订单表聚合。

**重点讲**：平台帮你算清楚每一分钱，不用再导 Excel。

## 遇到问题

| 现象 | 怎么办 |
|---|---|
| 双击 START.bat 一闪而过 | 右键 → 以管理员身份运行 |
| 提示"没有检测到 Docker" | 装 Docker Desktop，装完重启电脑 |
| 浏览器打不开 | 等 30 秒再刷新，首次启动慢 |
| 页面提示证书错误 | 点"高级"→"继续前往"，正常现象 |
| 端口被占用 | 关掉占用 80/443 端口的程序（如 IIS、其他 Web 服务） |

搞不定就截图发我。

## 一句提醒

演示环境里 16 张卡、6 个租户是演示数据（页面与数据里都标注了演示来源），
**但所有操作链路是真的**：
点下单会真的创建任务、点释放会真的回收资源、配额超了真的会被拦住、
告警规则真的会定时评估并投递、API 调用真的按 Token 扣费。

当前演示默认接了一个本机 k3s 真集群（`real` 模式）：节点、Pod、配额这些能读的
都读集群真实数据；没有 NVIDIA 硬件的部分（GPU Operator、DCGM 指标）界面会
如实标注"未接入"。客户提供带 NVIDIA 显卡的服务器后，接上即可把卡级数据也变成真的。
